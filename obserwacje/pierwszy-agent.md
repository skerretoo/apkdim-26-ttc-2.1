# Mój pierwszy agent — karta obserwacji

* Narzędzie i model: OpenCode - Muse Spark 1.3 Free
* Moje zadanie (2–3 zdania): Stworzenie natywnej aplikacji desktopowej dla Windowsa - generatora haseł. Powinien mieć możliwość wybierania długości haseł oraz wyboru dodatkowych dobrych praktyk zabezpieczenia hasła. Używanie Material Design.
* Pierwsza wiadomość (wklejona co do znaku): "Create a NATIVE desktop app suited for Windows 11 with newest versions of dependencies and newest premises of coding, NOT building with Electron or any similar. The app is an advanced password generator with selectable length, special character possibility, number presence possibility. All with a modern design following preferably material design-styled styling. It should last 3 generated passwords but NOT save them anywhere."
* Co agent zrobił najpierw: Sprawdził dostępność dotnet.
* O co pytał — i co zostało zatwierdzone bez czytania: Wszystko zostało wykonane bez pytania.
* Pierwszy błąd i co agent z nim zrobił: Niepoprawne referencje Material Design, wyszukał w Internecie prawidłowe i najnowsze biblioteki MD i zaktualizował referencje.
* Stan po 25 minutach: działa, po 6 minutach.
* Skąd wiem, że aplikacja działa (co zostało sprawdzone): Hasła generują się, wybieranie poszczególnych. 
* Rzeczy, które agent zrobił, a których nie rozumiem: Nie znam C#, więc wszystko?
* Jak mi się wydawało, że poszło (jedno zdanie): Zadanie zostało wykonane efektywnie, szybko i poprawnie w pierwszej próbie. Małe poprawki wymagane, dotyczące zbędnych opisów dokładnie z jakimi założeniami zostało wykonane zadanie w aplikacji, oraz braku dostatecznej czytelności kilku elementów (zmiana akcentowego koloru).
